Detailed Description

Ust seviye otomatik ACK/retry mesajlasma katmani konfigurasyonu.

Bu konfigurasyon, alt uartbin_config alanlarinin app katmanina uyarlanmis halidir. write hook'u uygulamanin verdigi user pointer'i ile cagrilir. on_message yalnizca gercek uygulama mesajlarini gorur; otomatik ACK response paketleri burada teslim edilmez.
