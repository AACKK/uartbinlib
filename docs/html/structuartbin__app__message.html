Detailed Description

Ust seviye app katmaninin uygulamaya teslim ettigi mesaj.

Bu katmanda ACK/seq/retry ayrintilari otomatik yonetilir. Uygulama yalnizca gercek mesajlari gorur; otomatik ACK response paketleri bu callback'e dusmez.
